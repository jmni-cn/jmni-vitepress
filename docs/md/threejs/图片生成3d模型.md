# 1. Tripo AI（目前最推荐）

https://www.tripo3d.ai/

优点：

- 一张图生成3D
- 多视角效果很好
- 自动PBR材质
- 自动UV
- 自动贴图
- 可以Rig
- 可以Remesh

导出支持：

✅ glb

✅ gltf

✅ obj

✅ fbx

质量：

⭐⭐⭐⭐⭐

很多Unity、Unreal开发者直接拿来做资产。

---

# 2. Rodin（Hyper3D）

https://hyper3d.ai/

这是目前业内评价最高的AI建模之一。

支持：

- Image to 3D
- Text to 3D
- Multi-view
- AI Retopo
- AI Texture

导出：

✅ GLB

✅ FBX

✅ OBJ

生成质量甚至比Meshy更稳定。

✅ GLB

✅ OBJ

适合：

- WebGL

# 如果你的目标是 Web（Three.js）

建议直接导出：

```
GLB
```

因为：

GLB 包含：

```
Mesh
Texture
Material
Animation（可选）
Skeleton（可选）
```

浏览器直接：

```javascript
const loader = new GLTFLoader();

loader.load("model.glb", (gltf)=>{
    scene.add(gltf.scene);
});
```

这是Three.js官方推荐格式。

## 我的推荐（按综合体验排序）

1. **Tripo AI** —— 综合效果最好，GLB 导出成熟，适合绝大多数场景。
2. **Rodin (Hyper3D)** —— 生成质量非常高，适合游戏和高质量资产。
3. **Meshy AI** —— 功能完善、社区成熟，适合快速生产。
4. **Hunyuan3D 2.0** —— 最值得尝试的开源方案，适合本地部署和二次开发。
5. **InstantMesh / TRELLIS** —— 如果你希望完全离线运行或集成到自己的 AI 工作流中，这两个开源项目值得关注。
